# api-types

TypeScript types for the Spring Boot API in `apps/products-api`, generated by
[`@hey-api/openapi-ts`](https://heyapi.dev) from `apps/products-api/build/openapi/openapi.json`.

`src/generated/` is gitignored. Nx regenerates it through the `codegen` target,
which depends on `products-api:generateOpenApi`.
